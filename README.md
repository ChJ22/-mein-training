# Mein Training – PWA (Version 1.0)

Eine einfache, installierbare Trainings-Web-App für iOS und Android.

## Veröffentlichung mit GitHub Pages
1. Neues **öffentliches** GitHub-Repository erstellen (z. B. `mein-training`).
2. Alle Dateien dieses Ordners ins Hauptverzeichnis des Repositorys hochladen.
3. Unter **Settings → Pages → Build and deployment** die Quelle **Deploy from a branch**, Branch **main**, Ordner **/(root)** auswählen und speichern.
4. Nach der Bereitstellung die angezeigte HTTPS-Adresse auf dem Smartphone öffnen.
5. iPhone: in Safari **Teilen → Zum Home-Bildschirm**. Android: in Chrome **Installieren** oder **Zum Startbildschirm hinzufügen**.

## Daten
Einträge werden lokal in `localStorage` gespeichert, nicht auf GitHub übertragen. Im Tagebuch können sie als JSON exportiert werden. Es gibt noch keine Synchronisierung, Benutzerkonten oder Cloud-Sicherung.

## Gesundheit
Die Übungen sind ein allgemeiner, vorsichtiger Einstieg und keine individuelle Therapie. Bei zunehmenden Beschwerden stoppen und medizinischen Rat einholen.
